# Flashcard Vibe Coding

## Overview

A command-line flashcard application developed through AI-assisted programming as a practical exploration of vibe coding.

The project began with the goal of creating a functional study tool and developed through iterative collaboration with an AI coding assistant.

## Features

- Create, edit, and delete flashcards
- Search questions and answers
- Sort cards by timestamp or question
- Save and load cards using JSON
- Quiz mode with answer checking
- Save quiz scores and review quiz history
- Calculate overall quiz performance
- Export all cards or keyword-filtered results

## Technology

- Python
- JSON for data persistence
- Python standard library

## Development Approach

This project explored using AI as a coding collaborator. Development involved defining requirements, requesting functionality, reviewing generated code, running the application, testing features, and evaluating the results.

My role focused on directing development, making decisions about functionality, testing behavior, and evaluating the resulting application.

The project demonstrates a practical approach to AI-assisted software development, including the importance of human direction and testing.

## Current Limitations

- Quiz questions may repeat within a session.
- Answer checking uses substring matching rather than semantic evaluation.
- The statistics menu currently reports the total number of cards; quiz performance is tracked separately.

## Future Considerations

Potential improvements include more flexible answer evaluation, expanded statistics, and additional testing.

## Disclaimer

This is a personal learning and portfolio project, not a production-grade application. AI-assisted development does not replace the need for code review, testing, and security considerations.
